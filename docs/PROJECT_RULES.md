# 프로젝트 작업 규칙 (필수 준수)

> ⚠️ **중요**: 이 문서의 규칙은 반드시 준수해야 합니다.

---

## 🚨 절대 규칙 (Absolute Rules)

### 1. 기획 Fixed - 임의 삭제 금지

**규칙:**
- 기획이 **확정된 상태**입니다
- 디자인 준거(스크린샷, 시안)에 있는 모든 요소는 **반드시 포함**되어야 합니다
- 임의로 요소를 빼거나 생략하면 **절대 안 됩니다**

**예시:**
```
❌ 잘못된 작업:
- 디자인에 있는 버튼을 "불필요해 보여서" 제거
- 검색 필터를 "간단하게 만들려고" 일부 옵션 삭제
- 정보 박스를 "공간이 부족해서" 2개만 표시

✅ 올바른 작업:
- 디자인 시안의 모든 요소를 그대로 구현
- 불필요해 보이는 요소도 디자인대로 포함
- 기획 변경이 필요하면 먼저 확인 요청
```

---

### 2. 디자인 임의 수정 금지

**규칙:**
- **디자이너가 따로 있는 프로젝트**입니다
- 디자인을 임의로 수정하면 **디자인 컨펌을 다시 받아야** 합니다
- 첨부 이미지(스크린샷, 시안)의 디자인을 **그대로** 구현해야 합니다

**절대 변경 금지 항목:**
1. **컬러 (Color)**
   - 텍스트 색상
   - 배경 색상
   - 버튼 색상
   - 보더 색상

2. **간격 (Spacing)**
   - 마진 (margin)
   - 패딩 (padding)
   - 요소 간 간격 (gap)

3. **폰트 크기 (Font Size)**
   - 제목 크기
   - 본문 크기
   - 버튼 텍스트 크기

4. **레이아웃 (Layout)**
   - 요소 배치
   - 정렬 방식
   - 그리드 구조

5. **기타 스타일**
   - 보더 두께 및 스타일
   - 그림자 (box-shadow)
   - 라운드 처리 (border-radius)
   - 투명도 (opacity)

**예시:**
```css
/* ❌ 임의 수정 금지 */
.search-btn {
    background: #FF5722;  /* 디자인: #F48F01 -> 임의로 변경하면 안 됨 */
    padding: 12px 20px;   /* 디자인: 10px 18px -> 임의로 변경하면 안 됨 */
    font-size: 16px;      /* 디자인: 14px -> 임의로 변경하면 안 됨 */
}

/* ✅ 디자인 그대로 적용 */
.search-btn {
    background: #F48F01;  /* 디자인 시안과 동일 */
    padding: 10px 18px;   /* 디자인 시안과 동일 */
    font-size: 14px;      /* 디자인 시안과 동일 */
}
```

## 📐 디자인 시안 활용 방법

### 1. 스크린샷 확인

작업 전 반드시 확인:
- 첨부된 이미지(스크린샷, 시안)를 정확히 확인
- 모든 요소의 위치, 크기, 색상 파악
- 불명확한 부분은 질문하기

### 2. 측정 도구 활용

정확한 수치 확인:
- 브라우저 개발자 도구로 기존 페이지 측정
- 스크린샷에서 픽셀 단위로 간격 측정
- 컬러 피커로 정확한 색상 코드 추출

### 3. 픽셀 퍼펙트 구현

**목표: 디자인 시안과 100% 일치**
```
✅ 체크리스트:
□ 모든 요소가 시안에 포함되어 있는가?
□ 색상이 정확히 일치하는가?
□ 간격이 정확히 일치하는가?
□ 폰트 크기가 정확히 일치하는가?
□ 레이아웃이 정확히 일치하는가?
```

## 🎨 Figma 파일 활용

### Figma 파일이 있는 경우

**Claude (AI)의 Figma 파일 읽기 능력:**
- ❌ **직접 읽기 불가능**: Claude는 Figma 파일(.fig)을 직접 열거나 읽을 수 없습니다
- ✅ **간접 활용 가능**: Figma에서 추출한 정보는 활용 가능합니다

**Figma 파일 활용 방법:**

1. **스크린샷 제공**
   ```
   - Figma에서 화면 캡처
   - PNG/JPG로 저장
   - Claude에게 이미지 제공
   → Claude가 이미지 분석하여 HTML/CSS 작성 가능
   ```

2. **디자인 스펙 제공**
   ```
   Figma "Inspect" 패널에서:
   - 색상 코드 (#F48F01)
   - 폰트 크기 (14px, 16px, 18px)
   - 간격 (margin: 20px, padding: 16px)
   - 크기 (width: 300px, height: 48px)

   → 텍스트로 정리해서 Claude에게 제공
   ```

3. **CSS 코드 추출**
   ```
   Figma에서 "Copy as CSS" 기능 사용
   → CSS 코드를 복사하여 Claude에게 제공
   → Claude가 KRDS 스타일과 통합
   ```

4. **컴포넌트 설명**
   ```
   "이 버튼은 주황색(#F48F01) 배경에
   흰색 텍스트, 14px 폰트 사이즈,
   패딩은 10px 18px,
   border-radius는 24px입니다"

   → Claude가 정확한 CSS 작성
   ```

**추천 작업 흐름:**
```
1. Figma에서 해당 페이지/컴포넌트 스크린샷 캡처
2. Inspect 패널에서 주요 스펙 확인 및 메모
3. 스크린샷 + 스펙을 Claude에게 제공
4. Claude가 HTML/CSS 작성
5. 브라우저에서 결과 확인
6. Figma와 비교하여 수정 요청
```

## 🔍 변경이 필요한 경우

### 디자인 변경 프로세스

**절대 임의로 변경하지 말 것!**

```
1. 문제 발견
   └─> 2. 사용자(또는 디자이너)에게 질문
        └─> 3. 승인 대기
             └─> 4. 승인 후 변경
                  └─> 5. 변경 내역 문서화
```

**질문 예시:**
```
"디자인 시안을 확인했는데,
검색 버튼의 색상이 #F48F01로 되어 있습니다.
그런데 기존 사이트의 Primary 색상 (#E67E00)과 다릅니다.
어떤 색상을 사용해야 할까요?"
```

```
"FAQ 페이지의 아코디언 항목이 시안에는 10개인데,
실제 데이터는 20개입니다.
페이지네이션을 추가해야 할까요?"
```

## ✅ 작업 체크리스트

### 작업 시작 전
- [ ] 디자인 시안(스크린샷) 확인
- [ ] Figma 파일이 있다면 스펙 추출
- [ ] 모든 요소 리스트업
- [ ] 불명확한 부분 질문

### 작업 중
- [ ] 디자인 시안을 항상 옆에 두고 비교
- [ ] 색상 코드 정확히 일치시키기
- [ ] 간격을 픽셀 단위로 측정하여 적용
- [ ] 폰트 크기 정확히 적용

### 작업 완료 후
- [ ] 브라우저에서 시안과 나란히 비교
- [ ] 모든 요소가 포함되었는지 확인
- [ ] 색상, 간격, 폰트 크기 일치 확인
- [ ] 반응형 동작 확인 (모바일, 태블릿)

## 🎯 작업 원칙 요약

1. **디자인 시안 = 법**
   - 시안에 있는 모든 것을 그대로 구현

2. **임의 판단 금지**
   - "이게 더 나아 보여" → ❌
   - "시안대로 구현" → ✅

3. **변경은 승인 후**
   - 필요하면 질문 → 승인 → 변경

4. **픽셀 퍼펙트**
   - 1px 차이도 중요함
   - 색상 코드 정확히 일치

5. **Figma 활용**
   - 스크린샷 + 스펙 제공
   - Claude가 정확히 구현

## ⚠️ 위반 시 문제점

### 임의로 디자인을 변경하면:
1. 디자이너가 다시 확인해야 함
2. 디자인 컨펌을 다시 받아야 함
3. 일정 지연 발생
4. 재작업 시간 소요

### 기획 요소를 임의로 삭제하면:
1. 기획 의도와 다른 결과물
2. 기획자 확인 필요
3. 전체 기획 재검토 가능성
4. 재작업 시간 소요
